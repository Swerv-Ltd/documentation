This guide demonstrates how to use the Swervpay Node.js SDK to create a customer, issue a card, create a collection account, and initiate a payout.

### Setup

Create a Swervpay business and copy its business ID and secret key from the dashboard. Keep these credentials on your server and never expose them in browser or mobile-app code. Before using production traffic, complete the [go-live checklist](/go-live-checklist).

### Install the SDK

Install [swervpay-node](https://www.npmjs.com/package/@swervpaydev/sdk) sdk into your new or existing NodeJS application using any of your favorite package manager.

<CodeGroup>
```bash npm
$ npm install @swervpaydev/sdk
```
```bash yarn
$ yarn add @swervpaydev/sdk
```
```bash pnpm
$ pnpm add @swervpaydev/sdk
```
```bash bun
$ bun install @swervpaydev/sdk
```
</CodeGroup>

### Usage

```javascript NodeJS
import { SwervpayClient } from "@swervpaydev/sdk";

const config = {
    secretKey: process.env.SWERVPAY_SECRET_KEY,
    businessId: process.env.SWERVPAY_BUSINESS_ID,
};

const swervpay = new SwervpayClient(config);

// Create a new customer
const customer = await swervpay.customer.create({
    firstname: "user",
    lastname: "user",
    middlename: "user",
    country: "user",
    email: "user@mailinator.com"
})

// Create a new card
await swervpay.card.create({
    customer_id: customer.id,
    amount: 10,
    currency: "USD",
    issuer: "MASTERCARD",
    type: "DEFAULT"
})

// Create a USD collection account for a customer
const collection = await swervpay.collection.create({
    customer_id: customer.id,
    currency: "USD",
    merchant_name: "Ada Okafor",
    amount: 0,
    type: "DEFAULT",
    additional_information: {
        account_type: "INDIVIDUAL",
        nin: "12345678901",
        tax_number: "12345678901",
        date_of_birth: "1994-04-12",
        employment_status: "EMPLOYED",
        account_designation: "PERSONAL",
        income_band: "UNDER_10000",
        source_of_income: "SALARY",
        address: {
            street: "12 Admiralty Way",
            city: "Lagos",
            state: "Lagos",
            country: "Nigeria",
            zip_code: "100001"
        },
        document: {
            type: "NIN",
            number: "12345678901",
            issue_date: "2020-01-01",
            expiry_date: "2030-01-01",
            urls: ["https://example.com/document-front.jpg"]
        },
        utility_bill: "https://example.com/utility-bill.pdf",
        bank_statement: "https://example.com/bank-statement.pdf"
    }
})

// Create a new payout
await swervpay.payout.create({
    bank_code: "044",
    account_number: "0690000000",
    amount: 8500,
    currency: "NGN",
    reference: "payout_reference",
    narration: "Customer payout"
})
```

Here, the client is initialized with server-side credentials. The customer ID returned from customer creation is then reused when issuing the card and creating the USD collection account. Each operation returns a response that you should persist or inspect before starting the next dependent operation. Persist the customer and collection IDs so you can retrieve their status later and reconcile webhook events.
