---
title: 'Overview'
description: 'Retrieve exchange rates and exchange supported currencies.'
---

The FX API supports rate lookup and currency exchange. Provide three-letter uppercase currency codes and an integer amount in the smallest currency unit used by the request.

### Supported Conversion

- USD to NGN
- NGN to USD

### 💵 Get Rate

To get the current conversion rate, use the [rate](/api-reference/fx/rate) endpoint.

**Body**

<ParamField body="to" type="string">
The three-letter ISO currency code in uppercase.
</ParamField>


<ParamField body="from" type="string">
The three-letter ISO currency code in uppercase.
</ParamField>


<ParamField body="amount" type="number">
 amount to convert in the smallest currency unit (e.g., cents, kobo).
</ParamField>

```json Request Body
{
    "from": "NGN",
    "to": "USD",
    "amount": 1
}
```


### 💵 Exchange

To convert from one currency to another, use the [exchange](/api-reference/fx/exchange) endpoint.

**Body**

<ParamField body="to" type="string">
The three-letter ISO currency code in uppercase.
</ParamField>


<ParamField body="from" type="string">
The three-letter ISO currency code in uppercase.
</ParamField>


<ParamField body="amount" type="number">
 amount to convert in the smallest currency unit (e.g., cents, kobo).
</ParamField>


```json Request Body
{
    "from": "NGN",
    "to": "USD",
    "amount": 1
}
```
