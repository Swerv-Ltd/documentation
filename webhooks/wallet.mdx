## Overview

Wallet webhooks notify your application when a wallet is created or updated. The current wallet event types are:

- `wallet.created`
- `wallet.updated`

Use the wallet ID to update the corresponding wallet record and reconcile the reported balance and amount.

## Updated webhook event

This event is fired when a wallet is updated.

```json wallet.updated
{
  "event": "wallet.updated",
  "data": {
    "wallet_id": "wlt_Za3WgMTHsD5NSYMeqRJ7",
    "business_id": "bsn_fAYcWSUXz3TogChv7BgH",
    "type": "CREDIT",
    "amount": 11000,
    "balance": 402850
  }
}
```
