---
title: 'Create Collection'
openapi: 'POST /collections'
---

Create a collection account for receiving payments. Collections support existing `NGN` virtual account flows and `USD` collection accounts.

## NGN collection

Use `NGN` collections for Naira virtual accounts. `ONE_TIME` collections require an `amount`. `DEFAULT` permanent collections require a `customer_id`.

```bash
curl -X POST https://api.swervpay.co/api/v1/collections \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "customer_id": "cus_123456789",
    "currency": "NGN",
    "merchant_name": "Swervpay",
    "amount": 10000,
    "type": "ONE_TIME"
  }'
```

## USD collection account

Use `USD` collections to issue a permanent USD collection account for an approved customer in an [eligible country](/collection/country-availability). USD collections must use `type` set to `DEFAULT` and must include `additional_information`.

The customer's approved KYC profile supplies the country, residential address, date of birth, phone number, and country-specific bank or national identifier. Do not replace those values in the collection request.

```bash
curl -X POST https://api.swervpay.co/api/v1/collections \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "customer_id": "cus_123456789",
    "currency": "USD",
    "merchant_name": "Ada Okafor",
    "amount": 0,
    "type": "DEFAULT",
    "additional_information": {
      "account_type": "INDIVIDUAL",
      "employment_status": "EMPLOYED",
      "account_designation": "PERSONAL",
      "income_band": "UNDER_10000",
      "source_of_income": "SALARY",
      "document": {
        "type": "NIN",
        "number": "12345678901",
        "issue_date": "2020-01-01",
        "expiry_date": "2030-01-01",
        "urls": ["https://example.com/document-front.jpg"]
      },
      "utility_bill": "https://example.com/utility-bill.pdf",
      "bank_statement": "https://example.com/bank-statement.pdf"
    }
  }'
```

<Note>
For USD collections, `type` must be `DEFAULT`, `customer_id` is required, and `additional_information` must include source-of-funds answers, the customer's government document, utility bill, and bank statement information.
</Note>

<Note>
The government-document type must be appropriate for the customer's KYC country. Supported values are `PASSPORT`, `NIN`, `NATIONAL_ID`, `DRIVERS_LICENSE`, `VOTERS_CARD`, and `GHANA_CARD`.
</Note>

<Note>
USD account issuance may complete asynchronously. Use the `collection.created` webhook to receive final bank details, or `collection.created.failed` to receive rejection reasons.
</Note>
