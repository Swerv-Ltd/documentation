---
title: 'Fund Card'
openapi: 'POST /cards/{id}/fund'
---

<RequestExample>

```bash cURL
curl -X POST https://api.swervpay.co/api/v1/cards/{id}/fund \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 2.5
  }'
```

```javascript Node.js
import { SwervpayClient } from '@swervpaydev/sdk';

const config = {
    secretKey: "<SECRET_KEY>",
    businessId: "<BUSINESS_ID>"
}

const swervpay = new SwervpayClient(config);

await swervpay.card.fund('<CARD_ID>', {
    amount: 2.5
})
```

```php PHP
use Swervpaydev\SDK\Swervpay;

$config = [
	'business_id' => '<BUSINESS_ID>',
	'secret_key' => '<SECRET_KEY>'
];

$client = new Swervpay($config);

$client->card()->fund('<CARD_ID>', [
    "amount" => 2.5
]);
```


```go Go
package main

import (
	"context"
	"fmt"
	"github.com/swerv-ltd/swervpay-go"
	"log"
)

func main() {
	ctx := context.Background()

	client := swervpay.NewSwervpayClient(&swervpay.SwervpayClientOption{
        BusinessID: "<BUSINESS_ID>",
        SecretKey: "<SECRET_KEY>",
    })

    data := swervpay.FundOrWithdrawCardBody{
        Amount: 2.5
    }

	resp, err := client.Card.Fund(ctx, "<CARD_ID>", data)

	if err != nil {
		log.Fatal("error", err.Error())
		return
	}
}
```

</RequestExample>

`amount` is expressed in the card currency's major unit and supports decimals. For example, `2.5` means USD 2.50, not 2.5 cents.
