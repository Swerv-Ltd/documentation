---
title: 'Overview'
description: 'Retrieve and inspect financial transaction records.'
---


The Transactions API provides a paginated view of financial activity, including amounts, fees, references, account details, types, and processing status.

### 🔍 Get All Transactions
Retrieve a list of all transactions processed through Swervpay using the [get all](/api-reference/transactions/get-all-transactions) transactions endpoint. Each record includes details such as amount, status, reference, and account information.


**Query Parameters**

<ParamField query="page" type="integer">
  The page to return.
</ParamField>


<ParamField query="limit" type="integer">
   The maximum number of results to return.
</ParamField>

**Response Example**

Returns an array of transaction objects, each containing details about individual transactions processed through the platform.

```json Response
[
  {
    "account_name": "Jane Doe",
    "account_number": "1234567890",
    "amount": 5000,
    "bank_code": "string",
    "bank_name": "Bank name",
    "category": "transfer",
    "charges": 50,
    "created_at": "2024-01-01T12:00:00Z",
    "detail": "Payment for services",
    "fiat_rate": 1.0,
    "id": "trans_789",
    "reference": "ref_101112",
    "report": false,
    "report_message": "",
    "session_id": "session_213",
    "status": "completed",
    "type": "debit",
    "updated_at": "2024-01-02T12:00:00Z"
  }
]
```

### 🔍 Get a Transaction
Retrieve details of a specific transaction using its unique ID with the [get transaction](/api-reference/transactions/get) endpoint.

**Path Parameters**

<ParamField path="id" type="string" required>
 The unique identifier of the transaction to retrieve.
</ParamField>

**Response Example**

Returns a transaction object containing details about the transaction.

```json Response
  {
    "account_name": "Jane Doe",
    "account_number": "1234567890",
    "amount": 5000,
    "bank_code": "string",
    "bank_name": "Bank name",
    "category": "transfer",
    "charges": 50,
    "created_at": "2024-01-01T12:00:00Z",
    "customer_id": "cust_456",
    "detail": "Payment for services",
    "fiat_rate": 1.0,
    "id": "trans_789",
    "reference": "ref_101112",
    "report": false,
    "report_message": "",
    "session_id": "session_213",
    "status": "completed",
    "type": "debit",
    "updated_at": "2024-01-02T12:00:00Z"
  }
```
